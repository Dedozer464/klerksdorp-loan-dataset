# Klerksdorp Loan Study: Employment Status vs. Loan Uptake

> **⚠️ Synthetic data.** Every record in this repository was generated by `python/generate_dataset.py`.
> No real person, lender, or credit bureau record is involved. The numbers illustrate an analysis workflow;
> they are **not** findings about the real population of Klerksdorp.

## Hypothesis
Unemployed adults in Klerksdorp are less likely to hold a loan than employed adults.

## Dataset (`data/klerksdorp_loans.csv`)
600 adults aged 18-64 (360 employed, 240 unemployed). One row per person, 12 columns, no missing values,
validated by assertions in the generator and `CHECK` constraints in `sql/schema.sql`.

| Column | Description |
|---|---|
| person_id | Unique ID (KLK-0001...) |
| age | 18-64 |
| gender | Female / Male |
| race | Black African / White / Coloured / Indian/Asian (Stats SA categories) |
| employment_status | Employed / Unemployed |
| sector | Public / Private / Not Applicable (unemployed) |
| occupation | Job type, or Not Applicable |
| monthly_income_zar | 0 for unemployed |
| has_loan | 1 / 0 |
| loan_type | Personal Loan, Vehicle Finance, Home Loan, Store Credit, Microloan, or None |
| loan_amount_zar, loan_term_months | 0 when no loan |

Demographic mix is loosely modelled on Matlosana/Klerksdorp (roughly 84% Black African, 11% White, 3% Coloured,
2% Indian/Asian; mining, public services and retail dominant). It is an approximation, not census data.

## Result
| Group | n | With loan | Rate |
|---|---|---|---|
| Employed | 360 | 144 | 40.0% |
| Unemployed | 240 | 79 | 32.9% |

Pearson chi-square = 3.094 (df = 1), **p = 0.079**, odds ratio 1.36 (95% CI 0.97-1.91).
The direction supports the hypothesis, but at alpha = 0.05 the result is **not statistically significant**.
The sample size and effect would need to be larger to claim a difference.

## Logistic regression (`python/logistic_regression.py`)
Every unemployed person has income = 0 and sector = "Not Applicable", so employment status, income and sector
cannot all go in one model (perfect collinearity). The analysis is therefore split in two:

**Model A, everyone (n=600): has_loan ~ employed + age**
| Term | OR | 95% CI | p |
|---|---|---|---|
| Employed (vs unemployed) | 1.39 | 0.98-1.99 | 0.068 |
| Age (per 10 yrs) | 0.96 | 0.80-1.14 | 0.622 |

**Model B, employed only (n=360): has_loan ~ age + income + sector**
| Term | OR | 95% CI | p |
|---|---|---|---|
| Age (per 10 yrs) | 0.92 | 0.73-1.17 | 0.513 |
| Income (per R10,000) | 1.07 | 0.82-1.40 | 0.605 |
| Public (vs private) | 1.26 | 0.73-2.17 | 0.403 |

Controlling for age barely moves the employment estimate (OR 1.36 unadjusted, 1.39 adjusted), and it stays
just short of significance. Within the employed, none of age, income or sector predicts loan uptake.
Both models explain almost nothing (McFadden pseudo-R2 < 0.005), which is expected because loan status was
assigned at random within each employment group.

## Run it
```bash
python python/generate_dataset.py   # regenerate CSV + SQL (seed 2026)
python python/analyze.py            # standard library only
python python/logistic_regression.py  # standard library only
node node/analyze.js                # no dependencies
node node/logistic_regression.js    # no dependencies

# SQL (SQLite example)
sqlite3 loans.db < sql/schema.sql
sqlite3 loans.db < sql/insert_data.sql
sqlite3 loans.db < sql/analysis.sql
```

## Limitations (read these)
- The group loan rates were fixed by design so that p lands near 0.08. A real study cannot do this.
- Employment and loan status are not causally linked in the generator beyond that fixed rate.
- Unemployed people with loans are mostly microloans/store credit with small balances; real lending data is messier.
